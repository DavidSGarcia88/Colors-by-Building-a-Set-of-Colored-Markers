# Colored Markers - CSS Design
This project showcases the creation of colored markers using HTML and CSS. It includes three different colored markers (red, green, and blue), each made up of a cap and a sleeve, styled with gradients and box shadows for a modern look.

## Features
- Three distinct color markers: Red, Green, and Blue.
- Each marker consists of a cap and a sleeve.
- Custom gradient backgrounds for each color.
- Responsive layout for various screen sizes.

# CSS Styling
## .h1
- Centers the title text on the page.
## .container
- A wrapper with padding and a white background for the markers.
## .marker
- Defines the basic structure of the markers (with cap and sleeve).
- Includes gradient background colors for the red, green, and blue variants.
## .cap & .sleeve
- Cap: A small block element that represents the top part of the marker.
- Sleeve: The longer part of the marker with custom styling (background color and border).
## Color Variants
- Red: A gradient from brown to red with a glowing effect (box-shadow).
- Green: A gradient from dark green to light green, with a soft shadow effect.
- Blue: A gradient from dark blue to light blue, featuring a subtle shadow.
## How to Use
1. Create an index.html file and copy the HTML code into it.
2. Create a styles.css file and copy the provided CSS code into it.
3. Open the index.html file in your browser to view the markers.

## Customization
Feel free to adjust the colors, sizes, and shadows to create your own unique marker designs. The HTML and CSS structure allows for easy modification and extension.

## Conclusion
This project demonstrates simple CSS design techniques, providing a colorful and creative visual element for any webpage. The design can be used as a template for more complex UI elements or decorative effects.
